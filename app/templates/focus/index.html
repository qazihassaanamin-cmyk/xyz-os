How this works

  • One session at a time. Starting a second is refused.
  • Time is measured by the server, so refreshing or closing the tab changes nothing.
  • A session only counts once it reaches {{ minimum_minutes }} minutes.
  • Pausing is allowed; paused time is not counted.
  • One completed session earns the daily focus credit. Further sessions are recorded without extra credit.
  • A session left paused for more than {{ pause_limit_minutes|default(30) }} minutes is recorded as interrupted.
