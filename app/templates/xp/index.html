What earns XP

Only verified events. The list below is what the system currently rewards.

Task accepted
40–350 XP by difficulty, released only when a reviewer approves it
Delivered before the deadline
+25 XP on accepted work
Marked high quality by the reviewer
+35 XP
Focus session completed
+20 XP, once per working day
Daily check-in and report
+10 and +15 XP, once each per working day
Blocker resolved
+40 XP, plus +30 XP for anyone who helped
Milestone completed
+120 XP
Suggestion implemented
+80 XP to the author
Knowledge entry published
+45 XP
Five-day streak
+25 XP at each milestone
Signing in, sending messages, creating trivial tasks and uploading unnecessary screenshots earn nothing.
